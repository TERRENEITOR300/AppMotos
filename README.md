# MotoRace — App de Inscripción al Torneo 🏍️

Aplicación web PWA para inscripción y seguimiento de pilotos en el torneo MotoRace.

## 📁 Archivos del proyecto

```
motorace-app/
├── index.html       → Aplicación principal
├── manifest.json    → Configuración PWA
├── sw.js            → Service Worker (funciona sin internet)
├── icon-192.png     → Ícono app (192x192 px) ← tú lo agregas
├── icon-512.png     → Ícono app (512x512 px)  ← tú lo agregas
└── README.md        → Este archivo
```

## ⚠️ Paso pendiente — Agregar íconos

Necesitas crear dos imágenes con el logo de tu app:
- `icon-192.png` → 192 x 192 píxeles
- `icon-512.png` → 512 x 512 píxeles

Puedes generarlos gratis en: https://favicon.io/favicon-generator/

## 🚀 Cómo publicar con GitHub Pages

1. Sube todos estos archivos a GitHub
2. Ve a **Settings → Pages**
3. Selecciona rama **main** y carpeta **/ (root)**
4. Guarda — en minutos tendrás tu URL pública

## 📱 Cómo instalar en el celular

**Android:** Abre la URL en Chrome → menú ⋮ → "Instalar app"  
**iPhone:** Abre en Safari → botón compartir → "Agregar a pantalla de inicio"

## 🔧 Tecnologías

- HTML / CSS / JavaScript puro
- Firebase Realtime Database
- PWA (Progressive Web App)
